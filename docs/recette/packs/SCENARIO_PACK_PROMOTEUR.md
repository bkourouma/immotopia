Recette du 30 septembre 2026, branche `fix/recette-packs-e2e`, exécutée dans le
navigateur intégré par l'agent de recette du pack **PROMOTEUR**. Le cadre
(règles, format des anomalies, livrables) est
[CADRE_COMMUN.md](CADRE_COMMUN.md) ; les prix et les règles de quota viennent de
[PLAN-ABONNEMENTS.md](../../architecture/PLAN-ABONNEMENTS.md) ; le socle
chantier/finance reprend le jeu de données de
[SCENARIO_TEST_E2E_CHANTIER_VERS_LOCATION.md](../../SCENARIO_TEST_E2E_CHANTIER_VERS_LOCATION.md)
(parties A et B — la partie « location » de ce document n'est PAS jouée : ce pack
ne l'ouvre pas, on vérifie son refus, partie C et R).

Le document est écrit AVANT l'exécution (parties 1 à 4) ; le journal
d'exécution et la matrice de couverture sont à la fin (parties 5 et 6).

### Réalité de l'environnement (pas des anomalies)

- Instance : web `http://promoteur.localhost:3303`, API `http://promoteur.localhost:8803`
  (curl : `http://127.0.0.1:8803`), base `immotopia_rec_promoteur`, vierge au départ.
- `SUBSCRIPTION_ENFORCEMENT=enforce` : menus masqués, routes refusées, quotas
  bloquants (politique « Bloquer ») ; paiement de plateforme en mode `SIMULATOR` ;
  e-mails captés par un récepteur local (boîte `mails/INDEX.md` du dossier de
  session, rien ne part) ; pas de WhatsApp ; ImmoCopilot avec le faux fournisseur
  déterministe ; cache des droits d'agence 30 s (recharger après une action du
  super-admin).
- Politique de dépassement par défaut d'une agence neuve : « Facturer le
  dépassement ». Essai gratuit de 30 jours, non désactivable.
- Défauts connus, corrigés dans une PR ouverte mais pas dans cette build (à
  signaler en une ligne, sans anomalie) : #63 (numérotation `-A2`, devise du bail
  dans les modèles DOCX), #64 (limiteurs ImmoCopilot), #67 (fiche d'un actif
  Patrimoine vide), #68 (inscription libre, fil d'Ariane admin, portail
  propriétaire), #69 (permissions PATRIMOINE_PERSONAL_*), #70 (exports de la
  situation patrimoniale), #71 (tantièmes spéciaux), #72 (programmation), **#73
  (le premier administrateur d'une agence provisionnée ne peut pas accepter son
  invitation : « bloquant (connu) », contournement à documenter)**, #74 (valeur
  calculée d'un bien Patrimoine).
- Aucun envoi WhatsApp : ne jamais cocher « WhatsApp » sur un téléphone.
- Écritures massives : les lots de programme du quota (150) sont créés par l'API
  autorisée (`POST /finance/sites/:siteId/lots`), noté « API seule » au journal.
- Un chantier ne se supprime pas ; rien n'est supprimé hors données du scénario.
  L'état « suspendu » n'a (a priori) aucune voie d'écriture : à constater, étape Q13.
