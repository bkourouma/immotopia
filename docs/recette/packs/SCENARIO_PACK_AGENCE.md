Scénario rédigé le 2026-09-30 **avant** exécution, puis rejoué par clics dans le
navigateur intégré (onglet propre à l'agent) ; le journal d'exécution et la
matrice de couverture sont à la fin du fichier. Cadre : `docs/recette/packs/CADRE_COMMUN.md`.

- Pack : `AGENCE` (MODULE_AGENCY) — fonctionnalités CORE + CRM + SALES + RENTAL + PATRIMOINE ; capacité **100 lots** ; 29 900 FCFA HT/mois ; mise en route 100 000.
- Instance : web `http://agence.localhost:3301`, API `http://agence.localhost:8801` (curl : `http://127.0.0.1:8801`), base `immotopia_rec_agence` (vierge).
- Branche : `fix/recette-packs-e2e`. Agent : recette AGENCE.
- Aucun mot de passe n'est consigné dans ce fichier : le super-admin est celui du seed
  `create-super-admin.ts` ; les mots de passe des comptes créés sont des valeurs de test conformes à la règle
  (8 car. min., majuscule, minuscule, chiffre, caractère spécial) et restent hors du dépôt.

## 0. Conventions

- N° d'étape `X-nn` (X = partie). Verdicts : `passé` (lu à l'écran) / `échoué (BUG-…)` / `bloqué (cause)` / `noté` (information).
- « API seule » = étape jouée par `curl` (cookie propre à l'agent) parce que l'interface ne le permet pas ou pour vérifier un état.
- `T` = identifiant de l'agence créée, `BASE` = `http://agence.localhost:3301/tenant/T`.
- Toutes les données sont fictives ; e-mails en `@exemple.test`, téléphones `+225 07 00 00 00 xx`.

- `SUBSCRIPTION_ENFORCEMENT=enforce` : menus masqués et routes refusées pour un module non souscrit ; quotas bloquants selon la politique de l'agence.
- Paiement en ligne de la plateforme en mode `SIMULATOR` ; e-mails captés localement (rien ne part) ; pas de WhatsApp ; ImmoCopilot avec le faux fournisseur déterministe ; cache des droits d'agence 30 s (recharger après une action du super-admin).
- Essai gratuit de 30 jours automatique (interrupteur coché et grisé) ; aucune facture pendant l'essai.
- Défauts connus déjà corrigés dans une PR ouverte (à ne signaler qu'en une ligne) : #63, #64, #67, #68, #69, #70, #71, #72, #73, #74.
